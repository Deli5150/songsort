# Changelog

## 1.0.1

- Previews are never left muted: YouTube's player remembers mute between sessions, so SongSort now
  always sets it explicitly.
- README screenshots.

## 1.0.0

First native release — a SwiftUI port of the Glaze SongSort app.

- Swipeable card deck for Liked Songs or any playlist, with ← / → / Space shortcuts.
- Add a song to several playlists at once, or create a new playlist inline.
- Playlist avatars on each card show where a song is already saved.
- Move mode, hide-already-filed, auto-play previews.
- Sorted progress from the Glaze app is imported on first launch.
- In-app updates from GitHub Releases.
